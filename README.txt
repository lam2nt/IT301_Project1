DISCOVER KOREA | IT301 STATIC WEBSITE
=====================================

OPEN LOCALLY
- Open index.html in any modern web browser.
- Use the main navigation to visit all five pages.
- Every page uses css/style.css and local images from images/.

PAGES
1. index.html         Home: reasons to visit, site navigation, search form.
2. history.html       History: kingdoms and historical timeline.
3. culture.html       Culture: food, traditions, language table, etiquette.
4. entertainment.html K-pop and K-dramas: music, stories, fan guide.
5. destinations.html  Seoul, Busan, Jeju Island, Gyeongju.

ASSIGNMENT FEATURES
- Exactly five different HTML pages, with index.html as home.
- Same header/nav/footer on every page, active page indicated.
- Semantic header/nav/main/section/article/aside/footer where appropriate.
- HTML comments in each page and CSS comments identifying media queries.
- One shared external stylesheet (css/style.css); no inline/internal CSS.
- Media queries at 900px and 640px for tablet and mobile devices.
- Two fonts: Georgia headings and Arial/Helvetica body text.
- Positioning: sticky header, relative image panels, absolute labels.
- Flexbox, margins, padding, borders, shadows, colors, classes and IDs.
- Local image files with meaningful alt text.
- A functional GET search form with required validation on the homepage.
- External links to the official Korean tourism sites.
- No JavaScript, Bootstrap, jQuery, React, or templates.

IMAGE CREDITS
- All nine JPEG illustrations were created specifically for this project.
- These are original stylized illustrations, not photographs.

FORM BEHAVIOR
- The homepage's optional search form sends only the typed search query
  to Google Search in a new tab. No information is stored by this website.
- A separate server is not required.

PUBLISH TO GITHUB PAGES
1. Create a GitHub repository and upload the contents of the project
   folder to its root. (Alternatively publish from a /docs folder.)
2. Go to Settings > Pages > Deploy from a branch.
3. Select the branch (usually main) and root folder; then Save.
4. Wait for GitHub to display your published site link.
5. Submit the full project folder and the published GitHub Pages link
   as instructed by the professor.

FACT CHECKING
VisitKorea: https://english.visitkorea.or.kr/
Visit Seoul: https://english.visitseoul.net/
South Korean travel facts are concise, illustrative descriptions, not
real-time opening hours, prices, or booking information.

VALIDATION
Validate HTML at https://validator.w3.org/nu/ and check Lighthouse
accessibility in Chrome before final submission. The files have been
checked for links, attributes, basic structure and accessible labels;
external validation is still a recommended final step.
